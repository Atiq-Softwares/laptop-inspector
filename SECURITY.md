# Security policy

Copyright © 2026 Atiq-Softwares. Developed by Atiq-Softwares.
Official profile: https://github.com/Atiq-Softwares

Report suspected vulnerabilities using this repository's private vulnerability
reporting option when available. If unavailable, use the profile to request a
private contact method without posting exploit details, reports, identifiers or
credentials publicly. No private reporting address is invented here.

Published v1.0/v1.1 and the v1.1.1 security update are unsigned. Their SHA-256 files provide integrity
checks; they do not prove a trusted Windows publisher. Do not bypass Windows
security controls. Hardware reports are point-in-time observations, not signed
certificates or guarantees of reliability.

The application has no external report-import feature. Do not treat edited
HTML/PDF/JSON files as executable instructions or authenticated inspection data.
Use an updated viewer. The app does not upload hardware data or require online
activation, device binding or permanent background services.

The v1.1.1 security update uses bounded diagnostic input, an explicitly
verified drive reader and transactional report exports. Required third-party
notices and corresponding GPL SMART-tool source remain part of distribution.
