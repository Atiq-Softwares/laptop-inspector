ATIQ-SOFTWARES / LAPTOP INSPECTOR 1.1

1. Extract the entire ZIP to a normal local folder.
2. Double-click Atiq-Laptop-Inspector.exe.
3. Click Start Full Inspection.
4. Review Hardware details, then complete Manual checks.
5. Open Export reports and save PDF, HTML or JSON.

No installation, administrator access, account or internet is required.
Keep this README, LICENSE, THIRD-PARTY-NOTICES.txt and the licenses and third-party folders with
the EXE when redistributing it. The EXE includes the x64 .NET runtime.
First start may extract native runtime files to Windows' temporary directory.

Compatibility: Windows 10 22H2 x64 and Windows 11 x64. Windows on ARM emulation,
32-bit Windows, Windows Server and virtual hardware are not qualified targets.
Use a Windows version supported by Microsoft for security updates.

This application is unsigned. Windows Defender/SmartScreen or organizational
application controls may warn or block it. Review the repository and checksum,
and follow your organization's policy. Do not disable protection or bypass a block.

Missing SMART, battery, TPM or sensor data is reported as unavailable. Driver and
firmware support varies. No automatic stress tests, malware scan, full drive
surface test, memory integrity test, or guarantee of future reliability.

Privacy: no automatic uploads, telemetry, credentials, serial numbers, computer
names, usernames, product keys, IP/MAC addresses or SSIDs. Manual notes are excluded
from exported reports by default. Review any notes you explicitly include.
